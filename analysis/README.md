# Analysis Utilities

This directory contains utility scripts for post-processing the output files generated by `exact-fgr`.

## fix_exponent.py

Some Fortran compilers may write floating-point numbers without the exponent marker `E`. For example,

```
0.2661808633-107
```

instead of

```
0.2661808633E-107
```

Such values cannot be correctly read by Python, NumPy, pandas, and many other analysis programs.

The script `fix_exponent.py` automatically inserts the missing `E` into malformed scientific notation.

### Usage

```bash
python fix_exponent.py
```

The script reads

```
validity_all.dat
```

and produces

```
validity_all_fixed.dat
```

The original data file is left unchanged.
